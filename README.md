# מערכת כשרות המקוואות – מערכת אחודה

ריפו זה מכיל שני חלקים:

1. **`app/`** – האפליקציה החדשה (PWA בעברית, RTL). כרטיס לכל מקווה עם כל הנתונים,
   יומן פעולות, דוחות פיקוח, משימות פתוחות ולוח בקרה. **זהו הבסיס למערכת האחודה.**
2. **קבצי ה-Apps Script** (`קוד.js`, `Alerts.js`, `Reports.js`, `Api.js`) – מערכת V2 הקיימת שקולטת
   הודעות מקבוצת הוואטסאפ דרך Green API, מנתחת אותן עם ג'מיני ורושמת ליומן דיווחים
   בגיליון. מסונכרן עם Apps Script דרך `clasp` (`sync.bat`).

## האפליקציה (`app/`)

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה המסכים והעיצוב |
| `app.js` | לוגיקה: רשימה, סינון, כרטיס מקווה, משימות, לוח בקרה |
| `hebdate.js` | ממיר תאריכים עבריים (ללא תלות חיצונית), מאומת מול טבלת התאריכים בגיליון |
| `data.js` | הנתונים – נוצר אוטומטית מהאקסל ע"י `tools/export_excel.py` |
| `config.js` | כתובת ה-API של הגיליון החי (ראה למטה) |
| `manifest.json`, `sw.js` | התקנה כאפליקציה בטלפון ועבודה לא-מקוונת |

הפעלה מקומית: לפתוח את `app/index.html` בדפדפן, או להריץ
`python3 -m http.server` בתוך `app/` (נדרש בשביל ה-Service Worker).
פריסה: להעלות את תיקיית `app/` לכל אירוח סטטי (GitHub Pages / Cloudflare Pages / Vercel).

### מסכים
- **מקוואות** – 1,006 כרטיסים עם חיפוש חופשי וסינון לפי איזור, מועצה, פיקוח, תוקף תעודה
  ופעילות. צבע הפס בכרטיס = מצב התעודה (ירוק בתוקף, כתום פג בקרוב, אדום פג תוקף).
- **כרטיס מקווה** – לשוניות: פרטים · אוצרות ומאגר · היסטוריית פעולות · דוחות פיקוח
  (כל דוח מחולק למדורים: גג, מאגר, זריעה, השקה, בור טבילה, טכני, חב"ד) · משימות · דיווחי וואטסאפ.
  כפתור "דיווח חדש" פותח את טפסי הדיווח.
- **משימות פתוחות** – כל משימות הריקון וההחלפה, עם עדיפות, ומעקב פקקים ומילוי חוזר.
- **לוח בקרה** – מדדים: תעודות בתוקף / פג תוקף / פג בקרוב, משימות דחופות, פעולות וביקורות השנה.
- **דיווחי וואטסאפ** – כל הדיווחים מיומן הדיווחים, מקושרים למקווה לפי שם או יישוב.
- **תכנון עבודה** – שלוש רשימות בלחיצה: *תעודות לחידוש* (פג תוקף / החודש / 3 / 6 / 12 חודשים,
  לפי איזור ומועצה), *מאגרים שרוקנו וממתינים למילוי* (ריקון מאגר שלא נרשמה אחריו החלפת אוצר),
  ו*ריקונים והחלפות מתוכננים*. כל רשימה ניתנת לייצוא לאקסל עם עמודת "שיבוץ" ריקה לחלוקת עבודה.
- **לוח בקרה** – "נתונים חיים": כמה מקוואות קיבלו תעודה, החליפו אוצרות, רוקנו מאגר, תוקנו או
  עברו ביקורת – לפי חודש עברי (בחירה), מתחילת השנה העברית, ובהשוואה לשנה הקודמת.
- **דיווח / עדכון** – כפתור בכותרת: מקלידים שם מקווה (השלמה אוטומטית), ואז בוחרים אחד
  משני הטפסים, בדיוק כמו טפסי Google המקוריים: **דו"ח פיקוח כשרות** (גג איסוף מי גשם,
  מאגר, אוצר זריעה, אוצר השקה, בור טבילה, שונות / טכני – אותם סעיפים, ניסוחים וסדר)
  או **דיווח פעולה** (בורר "פעולות": החלפת אוצר · ריקון מאגר · תיקון כשרות · פקק על הגג ·
  חידוש תעודה · אישור מילוי אוצר, והשדות מתחלפים לפי הבחירה). בוחרים סוג דיווח,
  והטופס נפתח בתוך המערכת (ריקון מאגר, החלפת אוצר זריעה/השקה/חב"ד, חידוש תעודה, טיפול/תיקון,
  ביקור, פקק על הגג, ודו"ח פיקוח מלא עם כל המדורים). השמירה כותבת ישירות לגיליון, באותן
  לשוניות ועמודות שטפסי Google כתבו אליהן בעבר, והכרטיס מתעדכן מיד.
- **דיונים** – במקום קבוצת הוואטסאפ: ערוץ כללי, **קבוצות לפי נושא** (בוחרים מי חבר בקבוצה,
  או "פתוחה לכולם"), ודיון לכל מקווה (גם בלשונית "דיון" בכרטיס). בכל הודעה אפשר לצרף
  **תמונה, סרטון או הקלטת קול** (הקלטה ישירות מהמערכת), להגיב עם **אימוג'י** (👍 ❤️ 😂 🙏 ✅ ❗),
  לצטט ולהשיב, ולאזכר @שם (שולח התראה אישית). סנכרון כל 40 שניות. נשמר בלשוניות
  "דיונים", "קבוצות דיון" ו"תגובות" בגיליון.
- **הדיונים כאפליקציה נפרדת** – קישור בדף הבית פותח את הדיונים לבד (`?app=talk`), עם manifest
  משלו, כך שאפשר להתקין בטלפון אייקון נפרד "דיונים" בלי לפתוח את כל המערכת.
- **חלוקת עבודה** – מסמנים שורות ב"תכנון עבודה" (מאגרים שרוקנו / תעודות לחידוש) ולוחצים
  "שלח לחלוקת עבודה". כל מפקח לוחץ "אני לוקח" על מה שהוא לוקח, זה נרשם לכולם ומופיע בדיון
  הכללי. "דווח ביצוע" פותח את הטופס המתאים, והשמירה סוגרת את המשימה. נשמר בלשונית "שיבוצים".
- **כניסה עם Google** – כל אחד נכנס עם חשבון Google שלו; השם והאימייל נרשמים אוטומטית
  בלשונית "משתמשים", וכל דיווח, הודעה, שיבוץ ותמונה נרשמים על שמו. גם דיווח שמגיע
  מהוואטסאפ נרשם על שם המשתמש הרשום לפי מספר הטלפון. המשתמש הראשון שנכנס הוא המנהל.
  תפקידים: מנהל · מפקח · בלנית · צופה. מסך "ניהול משתמשים" למנהל (תפקיד, השבתה, הוספה מראש).
  בלי הגדרת Google (ראה למטה) המערכת עובדת במצב "מי אני" הישן.
- **מדיה** – תמונות, סרטונים והקלטות קול בכל דיווח ובכל הודעה. התמונות מצטמצמות במכשיר,
  הכל נשמר בדרייב בתיקיית הארכיון של המקווה תחת "מהמערכת". לשונית **"מדיה"** בכרטיס מרכזת
  את כל המדיה של המקווה – מהדיווחים, מהדיונים ומהוואטסאפ – **עם הטקסט שנכתב לידה**, מי ומתי.
- **מי מדווח** – מי שנכנס עם Google, שמו כבר ממולא בכל טופס ואין צורך לכתוב אותו שוב
  (יש קישור "מדווח בשם מישהו אחר" למקרה חריג).
- **חזרה** – כפתור חזרה בכותרת בכל מסך, וכפתור "חזרה" בתוך הטפסים.
- **התראות אישיות** – אזכור @שם בדיון, פתיחת משימות לחלוקה, ולקיחה/סיום של משימה שפתחת,
  נשלחים כהודעת וואטסאפ אישית (גשר עד שיהיו התראות דחיפה). המשתמש מגדיר טלפון בתפריט שלו.
- **טפסים** – רשימת כל סוגי הדיווח בתוך המערכת. **אין הפניה לטפסי Google.** בלי חיבור לגיליון
  (או בלי אינטרנט) הדיווח וההודעה נשמרים במכשיר ("ממתינים לשליחה") ונשלחים אוטומטית
  ברגע שהאפליקציה מחוברת; הכרטיס מתעדכן מיד עם סימון "ממתין לשליחה".

### עדכון הנתונים מהאקסל
```bash
pip install openpyxl
python3 tools/export_excel.py "קובץ-המקוואות.xlsx" app/data.js
```
הסקריפט קורא את הגיליונות `בסיס הנתונים`, `אוצר זריעה`, `פיקוח הלכתי מערכת`,
`משימות לריקון והחלפת מי גשמים` ו-`-פקקים מילוי חוזר`, ומקשר הכל לפי שם המקווה.
שמות שלא נמצאו בבסיס הנתונים מודפסים בסוף הריצה (כדי לתקן איות בגיליון).

### חיבור חי לגיליון (שלב 2 – Apps Script API)
האפליקציה יכולה לקרוא את הנתונים ישירות מהגיליון במקום מ-`data.js`, דרך `Api.js`
שרץ באותו פרויקט Apps Script של מערכת V2 (כך גם דיווחי הוואטסאפ מגיעים לאפליקציה).

1. **Script Properties** (עורך ה-Apps Script ➜ הגדרות פרויקט ➜ מאפייני סקריפט):
   - `MIKVAOT_SHEET_ID` – מזהה גיליון המקוואות (מהכתובת `.../spreadsheets/d/<ID>/edit`).
     בגיליון חייבות להיות הלשוניות: `בסיס הנתונים`, `אוצר זריעה`, `פיקוח הלכתי מערכת`,
     `משימות לריקון והחלפת מי גשמים`, `-פקקים מילוי חוזר` (אותם שמות ועמודות כמו באקסל).
   - `API_TOKEN` – (רשות) סיסמה שהאפליקציה שולחת. ריק = ללא אימות.
2. **פריסה**: `clasp push` (או `sync.bat`) ואז Deploy ➜ Manage deployments ➜ New version.
   כתובת ה-Web App נשארת אותה כתובת שמשמשת את ה-Webhook של Green API.
3. **בדיקה**: לפתוח בדפדפן `<WebApp URL>?action=ping` – אמור להחזיר JSON עם `"found": true`
   לכל לשונית. `?action=data` מחזיר את כל הנתונים.
4. **האפליקציה**: בקובץ `app/config.js` למלא `apiUrl` (כתובת ה-Web App) ו-`apiToken`.
   בכותרת האפליקציה יופיע "מחובר לגיליון" עם שעת העדכון. אם אין רשת או שהחיבור נכשל,
   האפליקציה ממשיכה לעבוד מהעותק המקומי (`data.js`) ומציגה "אין חיבור לגיליון".

### כתיבה מהאפליקציה לגיליון (`ApiWrite.js`)
`POST <WebApp URL>?action=...&token=...` עם גוף JSON `{ user: {name, phone}, data: {...} }`.
Green API לא שולח פרמטר `action`, ולכן קולט הוואטסאפ לא מושפע.

| פעולה | נכתב ל | הערות |
|---|---|---|
| `addAction` | `אוצר זריעה` | אותן 22 עמודות של טפסי Google (ריקון מאגר, החלפת אוצר, חידוש תעודה...) |
| `addInspection` | `פיקוח הלכתי` | 79 עמודות כמו טופס דו"ח הפיקוח. **הנחה:** לשונית `פיקוח הלכתי מערכת` נגזרת ממנה בנוסחאות, כמו מהטופס |
| `addMessage` | `דיונים` (נוצרת אוטומטית) | הודעה כללית או על מקווה |
| `addWorkItems` / `updateWorkItem` | `שיבוצים` (נוצרת אוטומטית) | פתיחת משימות לחלוקה, "אני לוקח", "בוצע", שחרור |
| `addMedia` | `מדיה` + דרייב | תמונה / סרטון / הקלטה (base64, עד 25MB), משותפים לצפייה בקישור |
| `addGroup` / `updateGroup` | `קבוצות דיון` | קבוצה לפי נושא, רשימת חברים, פתוחה לכולם, ארכוב |
| `react` | `תגובות` | תגובת אימוג'י להודעה (לחיצה שנייה מסירה) |
| `perms` / `setPerms` | `הרשאות` | טבלת ההרשאות לפי תפקיד (מנהל בלבד) |
| `login` / `logout` / `updateMe` | `משתמשים`, `סשנים` | כניסה עם Google ID token, יציאה, טלפון להתראות |
| `users` / `addUser` / `updateUser` | `משתמשים` | ניהול משתמשים (מנהל בלבד) |

`?action=sync&since=<ISO>` מחזיר הודעות חדשות + כל השיבוצים (לסנכרון האפליקציה).
כשמוגדר `GOOGLE_CLIENT_ID`, כל כתיבה דורשת טוקן סשן של משתמש מחובר והשם נלקח מהסשן
(לא מהלקוח). בלי הגדרה זו – מצב ישן: שם חופשי מהמכשיר, בהגנת `API_TOKEN` בלבד.

### כניסה עם Google (`Auth.js`)
1. ב-[Google Cloud Console](https://console.cloud.google.com/apis/credentials): APIs & Services ➜
   Credentials ➜ Create credentials ➜ **OAuth client ID** ➜ Web application.
   ב-**Authorized JavaScript origins** להוסיף את כתובת האתר של האפליקציה (למשל
   `https://<user>.github.io`), ובפיתוח מקומי גם `http://localhost:8000`.
   (אם זו הפעם הראשונה, יש להגדיר קודם OAuth consent screen; מספיק External + הוספת
   המשתמשים כ-Test users, או פרסום.)
2. את ה-Client ID לשים ב-`app/config.js` (`googleClientId`) וב-Script Property `GOOGLE_CLIENT_ID`.
3. (רשות) `DEFAULT_ROLE` – תפקיד למשתמש חדש שנכנס בלי הוספה מראש (ברירת מחדל: מפקח).
   `NOTIFY_WHATSAPP=1` – התראות אישיות בוואטסאפ (דורש את ההגדרות של Green API מ-Alerts.js).
4. הסשן נשמר במכשיר ל-90 יום. הסקריפט מאמת כל כניסה מול Google (tokeninfo) ובודק שהטוקן
   שייך ל-Client ID שלנו. הלשוניות "משתמשים" ו"סשנים" נוצרות אוטומטית.

### מי רשאי לעשות מה (מסך "הגדרות והרשאות")
מנהל רשאי לכל הפעולות תמיד. לכל תפקיד אחר (מפקח / בלנית / צופה) יש טבלת הרשאות הניתנת
לעריכה במסך, לכל פעולה בנפרד: דיווח פעולה, דו"ח פיקוח, כתיבה בדיונים, העלאת מדיה, תגובות,
פתיחת ועריכת קבוצות, פתיחת משימות ולקיחתן, עריכת מקווה והוספת מקווה. נשמר בלשונית
"הרשאות" בגיליון ונכנס לתוקף מיד (גם על מי שכבר מחובר).

### עדכון חי מהוואטסאפ לתיק המקווה (`WhatsappActions.js`)
ג'מיני מזהה בכל דיווח גם את הפעולה שבוצעה (`action_type`: ריקון מאגר / החלפת אוצר / מילוי אוצר /
חידוש תעודה / תיקון / ביקור), את האוצר ואת תאריך הביצוע אם צוין. כשהמקווה מזוהה בוודאות,
נרשמת שורה בלשונית הפעולות של גיליון המקוואות, בדיוק כמו דיווח מהטופס, וכך היא מופיעה מיד
בכרטיס. חידוש תעודה מקבל תוקף אוטומטי לאותו חודש עברי בשנה הבאה.
- הפעלה: Script Property בשם `WA_AUTO_ACTIONS` עם הערך `1` (ברירת מחדל כבוי).
- מה נרשם מופיע גם בעמודת "הערות עיבוד" בלשונית "תור נכנס" ("נרשם בתיק: ...").
- בדיקה: להריץ `testWhatsappAction` מעורך הסקריפט (רושם שורת בדיקה שאפשר למחוק).

### תזכורת תעודות בוואטסאפ (`Reminders.js`)
`certificateReminder` שולח לצ'אט ההתראות (`ALERT_CHAT_ID`) רשימה של מקוואות בפיקוח שתעודתן
פגה או פגה בתוך `REMINDER_DAYS` ימים (ברירת מחדל 45). להריץ פעם אחת `installReminderTrigger`
לטריגר שבועי (יום ראשון 08:00). `testCertificateReminder` מדפיס בלי לשלוח.

### ייצוא לאקסל
בכל מסך (מקוואות, משימות, דיווחי וואטסאפ) ובכרטיס המקווה (פעולות, דוחות פיקוח) יש כפתור
"ייצוא לאקסל" שמייצא בדיוק את מה שמסונן על המסך לקובץ `.xlsx` (ללא רשת – `.csv`).
