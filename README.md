# מערכת כשרות המקוואות – מערכת אחודה

ריפו זה מכיל שני חלקים:

1. **`app/`** – האפליקציה החדשה (PWA בעברית, RTL). כרטיס לכל מקווה עם כל הנתונים,
   יומן פעולות, דוחות פיקוח, משימות פתוחות ולוח בקרה. **זהו הבסיס למערכת האחודה.**
2. **קבצי ה-Apps Script** (`קוד.js`, `Alerts.js`, `Reports.js`, `Api.js`) – מערכת V2 הקיימת שקולטת
   הודעות מקבוצת הוואטסאפ דרך Green API, מנתחת אותן עם ג'מיני ורושמת ליומן דיווחים
   בגיליון. מסונכרן עם Apps Script דרך `clasp` (`sync.bat`).

## האפליקציה (`app/`)

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה המסכים והעיצוב |
| `app.js` | לוגיקה: רשימה, סינון, כרטיס מקווה, משימות, לוח בקרה |
| `hebdate.js` | ממיר תאריכים עבריים (ללא תלות חיצונית), מאומת מול טבלת התאריכים בגיליון |
| `data.js` | הנתונים – נוצר אוטומטית מהאקסל ע"י `tools/export_excel.py` |
| `config.js` | כתובת ה-API של הגיליון החי (ראה למטה) |
| `manifest.json`, `sw.js` | התקנה כאפליקציה בטלפון ועבודה לא-מקוונת |

הפעלה מקומית: לפתוח את `app/index.html` בדפדפן, או להריץ
`python3 -m http.server` בתוך `app/` (נדרש בשביל ה-Service Worker).
פריסה: להעלות את תיקיית `app/` לכל אירוח סטטי (GitHub Pages / Cloudflare Pages / Vercel).

### מסכים
- **מקוואות** – 1,006 כרטיסים עם חיפוש חופשי וסינון לפי איזור, מועצה, פיקוח, תוקף תעודה
  ופעילות. צבע הפס בכרטיס = מצב התעודה (ירוק בתוקף, כתום פג בקרוב, אדום פג תוקף).
- **כרטיס מקווה** – לשוניות: פרטים · אוצרות ומאגר · היסטוריית פעולות · דוחות פיקוח
  (כל דוח מחולק למדורים: גג, מאגר, זריעה, השקה, בור טבילה, טכני, חב"ד) · משימות · דיווחי וואטסאפ.
  כפתור "דיווח חדש" פותח את טפסי הדיווח.
- **משימות פתוחות** – כל משימות הריקון וההחלפה, עם עדיפות, ומעקב פקקים ומילוי חוזר.
- **לוח בקרה** – מדדים: תעודות בתוקף / פג תוקף / פג בקרוב, משימות דחופות, פעולות וביקורות השנה.
- **דיווח וטפסים** – קישורים לטפסי Google הקיימים (עד שייבנו בתוך המערכת).

### עדכון הנתונים מהאקסל
```bash
pip install openpyxl
python3 tools/export_excel.py "קובץ-המקוואות.xlsx" app/data.js
```
הסקריפט קורא את הגיליונות `בסיס הנתונים`, `אוצר זריעה`, `פיקוח הלכתי מערכת`,
`משימות לריקון והחלפת מי גשמים` ו-`-פקקים מילוי חוזר`, ומקשר הכל לפי שם המקווה.
שמות שלא נמצאו בבסיס הנתונים מודפסים בסוף הריצה (כדי לתקן איות בגיליון).

### חיבור חי לגיליון (שלב 2 – Apps Script API)
האפליקציה יכולה לקרוא את הנתונים ישירות מהגיליון במקום מ-`data.js`, דרך `Api.js`
שרץ באותו פרויקט Apps Script של מערכת V2 (כך גם דיווחי הוואטסאפ מגיעים לאפליקציה).

1. **Script Properties** (עורך ה-Apps Script ➜ הגדרות פרויקט ➜ מאפייני סקריפט):
   - `MIKVAOT_SHEET_ID` – מזהה גיליון המקוואות (מהכתובת `.../spreadsheets/d/<ID>/edit`).
     בגיליון חייבות להיות הלשוניות: `בסיס הנתונים`, `אוצר זריעה`, `פיקוח הלכתי מערכת`,
     `משימות לריקון והחלפת מי גשמים`, `-פקקים מילוי חוזר` (אותם שמות ועמודות כמו באקסל).
   - `API_TOKEN` – (רשות) סיסמה שהאפליקציה שולחת. ריק = ללא אימות.
2. **פריסה**: `clasp push` (או `sync.bat`) ואז Deploy ➜ Manage deployments ➜ New version.
   כתובת ה-Web App נשארת אותה כתובת שמשמשת את ה-Webhook של Green API.
3. **בדיקה**: לפתוח בדפדפן `<WebApp URL>?action=ping` – אמור להחזיר JSON עם `"found": true`
   לכל לשונית. `?action=data` מחזיר את כל הנתונים.
4. **האפליקציה**: בקובץ `app/config.js` למלא `apiUrl` (כתובת ה-Web App) ו-`apiToken`.
   בכותרת האפליקציה יופיע "מחובר לגיליון" עם שעת העדכון. אם אין רשת או שהחיבור נכשל,
   האפליקציה ממשיכה לעבוד מהעותק המקומי (`data.js`) ומציגה "אין חיבור לגיליון".

### ייצוא לאקסל
בכל מסך (מקוואות, משימות, דיווחי וואטסאפ) ובכרטיס המקווה (פעולות, דוחות פיקוח) יש כפתור
"ייצוא לאקסל" שמייצא בדיוק את מה שמסונן על המסך לקובץ `.xlsx` (ללא רשת – `.csv`).

## מפת הדרכים למערכת האחודה

| שלב | תוכן | מצב |
|---|---|---|
| 1 | כרטיס לכל מקווה מנתוני האקסל, רשימה, משימות, לוח בקרה | ✅ בוצע |
| 2 | חיבור חי לגיליון: Apps Script מגיש API (JSON) במקום `data.js`, כולל דיווחי הוואטסאפ | ✅ בוצע (נדרשת הגדרה, ראה למעלה) |
| 3 | טפסי הדיווח (פיקוח, ריקון מאגר, החלפת אוצר זריעה/השקה, טיפול בור) בתוך המערכת: כפתור "דיווח / עדכון" ➜ בחירת מקווה ➜ טופס ➜ כתיבה ישירה לגיליון בתאריך עברי. מפרט השדות: `docs/forms.md` | 🟡 חלון הבחירה קיים, הטפסים עדיין ב-Google Forms |
| 4 | הצגת דיווחי הוואטסאפ (יומן הדיווחים של V2) בלשונית "דיווחי וואטסאפ" של המקווה ובמסך נפרד, כולל קישורי מדיה | ✅ בוצע (עם החיבור החי) |
| 5 | קליטת פרויקטי הבנייה/שיפוץ (צ'ק-ליסט, מפקחים, מדיה) מהאפליקציה הישנה `Daft-cashrut` כלשונית "פרויקטים" בכרטיס המקווה | ⬜ |
| 6 | משתמשים והרשאות (מנהל / רב מפקח / בלנית), התראות על תעודות שפגות ומשימות דחופות | ⬜ |

מקורות שהמערכת האחודה מחליפה בהדרגה: קובץ האקסל / גיליון המקוואות, חמשת טפסי Google,
מערכת V2 (וואטסאפ) ואפליקציית `Daft-cashrut` (פיקוח בנייה ושיפוצים, Supabase).
