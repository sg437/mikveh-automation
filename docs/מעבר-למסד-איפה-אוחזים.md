# מעבר למסד נתונים משלנו — איפה אוחזים

עודכן: 7 באוקטובר 2026. ענף: `claude/festive-lovelace-hmhp6d` (עוד לא מוזג ל-main).

## המטרה

להפסיק לעבוד על גיליון השיטס (קישורים, VLOOKUP, 23 שניות טעינה) ולבנות מסד נתונים
משלנו. מעכשיו והלאה כל הנתונים נשמרים במסד, והשיטס נשאר כארכיון.

## מה נעשה

1. **מיפוי מלא של השיטס** — כל 30 הלשוניות (כולל 10 מוסתרות), כל הנוסחאות והקישורים.
   התוצאה: [`מיפוי-הגיליון.md`](מיפוי-הגיליון.md).
   - שלושה מקורות אמיתיים: מקוואות (1,006), יומן פעולות (4,082), דוחות פיקוח (617).
   - כל השאר — חישובים ותצוגות, שיהפכו לקוד ולמסכים.
2. **הכרעות על השמות** — [`מיפוי-שמות-יתומים.md`](מיפוי-שמות-יתומים.md), והקובץ שהייבוא
   יקרא: [`tools/migration/name-decisions.json`](../tools/migration/name-decisions.json).
   - 52 שמות שויכו למקווה קיים; 58 לתור "לא משויכות".
   - 27 רשומות אוחדו כבורות של מקווה; 2 שמות כפולים הוכרעו.
3. **כל השאלות הפתוחות נענו.**

## ההחלטות שהתקבלו (פירוט בסעיף 5 של המיפוי)

| נושא | החלטה |
|---|---|
| שמות מקוואות | קבועים, נבחרים מהמסד. מקווה חדש ← ממתין לאישור מנהל + מייל |
| בורות | כמה בורות בתיקייה (1, 2, 3..., חב"ד, כלות), סדר מימין לשמאל |
| מאגרים | אפשר כמה מאגרים (מאגר 1, 2...), כל אחד עם הקטגוריות שלו |
| כלים | לשונית "כלים" נפרדת בתיקייה |
| תאריכים | לכל פעולה: תאריך ביצוע + תאריך עברי של יום הביצוע (מחושב) + תאריך רישום |
| היסטוריה | שום דבר לא נמחק ולא נדרס; יומן שינויים לכל תיק |
| רשומות לא משויכות | תור למנהל: שיוך / מחיקה סופית. "מקווה חדש" מסומן בנפרד |
| סגירת מקווה | מסומן "נסגר" עם תאריך וסיבה; לא נמחק; אפשר לפתוח מחדש |
| "רשימה ישן" (AR) | שדה ארכיון בכרטיס, לקריאה בלבד |
| "גברים" בפעילות | טעות — ייובא כ"פעיל" |
| ביקור/תיקון כשרות | נרשמים ביומן בלבד |
| עמודה L ביומן | תאריך החלפת האוצר בפועל — ישמש כתאריך הביצוע |

## ⚠️ דחוף — ממתין להחלטה

`app/data.js` בריפו הציבורי מכיל **753 שמות אחראים/בלניות ו-769 טלפונים**. הוא גלוי
בריפו, בהיסטוריית הגרסאות, ומתפרסם באתר (בכתובת ישירה, גם אם מסך הנעילה לא טוען אותו).

אפשרויות:
1. להעביר את הריפו לפרטי (Settings ← General ← Danger Zone ← Change visibility)
   ולעבור לאירוח שעובד עם ריפו פרטי (Cloudflare Pages, חינם). GitHub Pages ייפסק.
2. קודם להוציא את `data.js` מהאתר הנוכחי.

## מאיפה מתחילים בפעם הבאה

1. **להחליט על `data.js` והריפו** (למעלה).
2. **לאשר את המסד: Supabase** (Postgres מנוהל, כניסה עם Google, הרשאות, חינם בהיקף שלנו).
   אם מאשרים — לפתוח חשבון ב-supabase.com ופרויקט חדש באזור Frankfurt.
3. ואז אני:
   - בונה את מבנה הטבלאות לפי סעיף 6 במיפוי (כולל בורות, מאגרים, יומן שינויים, תור לא משויכות);
   - כותב סקריפט ייבוא מהאקסל, עם ההכרעות מ-`name-decisions.json`;
   - מריץ ייבוא ניסיון ומשווה מספרים מול השיטס;
   - מחבר את האפליקציה לקריאה מהמסד, ואחר כך גם לכתיבה.
